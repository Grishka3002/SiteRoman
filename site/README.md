# Сайт Романа Шумилова — production-версия

Статический сайт (HTML + CSS + минимальный JS), собранный по макетам
`../*.dc.html` (см. `../design_handoff_site/README.md`), плюс Node-сервер
с админ-панелью (см. `../server.js`).

## Структура
- `index.html` — Главная (развилка Свадьбы / Корпоративы)
- `svadby.html` — Свадьбы
- `korporativy.html` — Корпоративы
- `css/styles.css` — общие стили (токены, компоненты, media-query ≤820px)
- `js/main.js` — бургер-меню, квиз (валидация телефона, отправка заявки на
  `/api/inquiry`, состояние «отправлено»), deep-links мессенджеров
- `assets/` — фото, видео, шрифты; `assets/uploads/` — загруженное через админку

Все редактируемые тексты помечены `data-edit`, фото-ленты — `data-photos`,
видео — `data-videos`, бегущие строки — `data-marquee`. Сервер подставляет
правки из `../data/content.json` при отдаче страниц; сами HTML-файлы хранят
исходные (дефолтные) тексты.

## Запуск
```
npm install
npm start          # http://localhost:3000
```

## Админ-панель
`http://localhost:3000/admin` — пароль по умолчанию `roman2026`
(сменить: переменная окружения `ADMIN_PASSWORD`).

Возможности:
- редактирование всех надписей трёх страниц (по секциям);
- фото-ленты: добавить / удалить / заменить фото, порядок, кадрирование, alt;
- видео: добавить / удалить / порядок;
- бегущие строки: список фраз;
- «Заявки» — входящие с квиза (`../data/inquiries.json`), с удалением;
- сброс страницы к исходному виду.
