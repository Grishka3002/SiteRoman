# Сайт Романа Шумилова — production-версия

Статический сайт (чистый HTML + CSS + минимальный JS), собранный по макетам
`../*.dc.html` (см. `../design_handoff_site/README.md`).

## Структура
- `index.html` — Главная (развилка Свадьбы / Корпоративы)
- `svadby.html` — Свадьбы
- `korporativy.html` — Корпоративы
- `css/styles.css` — общие стили (токены, компоненты, media-query ≤820px)
- `js/main.js` — бургер-меню, квиз (валидация телефона, состояние «отправлено»), deep-links мессенджеров
- `assets/` — фото, видео, шрифты (копия из корня проекта)

## Запуск локально
Любой статический сервер, например:
```
npx serve site
```
