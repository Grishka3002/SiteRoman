# shymilovroman.ru static copy

Автономная копия сайта для деплоя на Railway или любой Node-хостинг.

## Запуск локально

```bash
npm start
```

По умолчанию сайт откроется на `http://localhost:3000`.

## Деплой на Railway

1. Загрузите репозиторий в GitHub.
2. Создайте новый Railway Project из GitHub repo.
3. Railway сам запустит команду `npm start`.

## Страницы

- `/`
- `/wedding`
- `/corporate`
- `/privacy`
- `/admin`

Основные изображения, шрифты, CSS, JS, Lottie JSON и Kinescope MP4 лежат локально в `public/assets`.

## Админ-панель

Админка открывается по адресам:

- `/admin/home` — главная;
- `/admin/wedding` — свадьба;
- `/admin/corporate` — корпоративы.

Локальный пароль по умолчанию: `admin123`.

Для Railway задайте переменную окружения:

```bash
ADMIN_PASSWORD=ваш_сложный_пароль
```

Через админку можно:

- менять существующий контент на страницах через раздел `Контент страниц`;
- добавлять фото и видео на нужную страницу;
- добавлять отзывы с аватаром;
- редактировать HTML страниц целиком в расширенном режиме.

Данные админки лежат в `data/cms.json`, загруженные файлы — в `public/uploads`. На Railway для долгого хранения загрузок лучше подключить Volume, иначе файлы, добавленные через админку после деплоя, могут пропасть при пересборке контейнера.
