# Handoff: Сайт ведущего Романа Шумилова (3 страницы)

## Overview
Редизайн сайта shymilovroman.ru. Тёмная «премиум» тема (графит + бронза/золото, жёлтый — точечный акцент), стиль «Кинолента»: вертикальные бегущие фото-ленты в герое, тайпрайтер-подзаголовки, бегущие строки фактов. Три страницы: Главная (развилка) → Свадьбы → Корпоративы. Цель каждой страницы — довести до формы «Рассчитать стоимость» (#quiz).

## About the Design Files
Файлы `*.dc.html` в этом проекте — **дизайн-референсы, созданные в HTML** (прототипы вида и поведения), а НЕ production-код. Задача: **воссоздать эти макеты в целевом окружении** (если кодбазы ещё нет — рекомендуемый стек: статический сайт на Astro/Next.js или чистый HTML+CSS+минимальный JS; хостинг Railway/любой Node — см. README старого сайта). Не копировать разметку напрямую: `support.js` — служебный рантайм предпросмотра, в production не нужен.

## Fidelity
**High-fidelity.** Цвета, типографика, отступы, тексты и анимации — финальные. Воспроизводить пиксель-в-пиксель. Все тексты взяты с действующего сайта и согласованы — не переписывать.

## Interactions & Behavior
- Навигация: обычные ссылки между страницами; все CTA ведут на `#quiz` той же страницы (плавный скролл приветствуется).
- Hover: аутлайн-кнопки → заливка `#C6A15B`, текст `#141416` (transition .3–.35s); бронзовые CTA → `#FFE40F`; ссылки: `a {color:#C6A15B}`, hover `#FFE40F`.
- FAQ — нативные details/summary.
- Формы: сейчас макетные. В production: квиз отправляет заявку (дата, город, имя/компания, телефон, выбранный подарок) — на бэкенд старого сайта (data/inquiries.json) или в Telegram-бот; кнопки мессенджеров — deep-links (wa.me, t.me и т.д.).
- Видео: mp4, controls, preload=metadata, вертикальные 9:16 (веб-аналог reels).

## Animations (все определены в @keyframes каждой страницы)
- `rshRise`: появление контента — translateY(46px)→0 + fade, .9s cubic-bezier(.22,.8,.24,1), каскад задержек .15/.35/.5/.62/.74s
- `rshMarqUp`: фото-ленты — translateY(0→-50%), 34–36s linear infinite (вторая колонка — reverse); контент дублируется для бесшовности
- `rshMarq`: бегущая строка — translateX(0→-50%), 24–28s linear infinite
- `rshPulse`: жёлтая точка лого — расходящаяся тень box-shadow, 2.6s infinite
- `rshCaret`: каретка тайпрайтера — мигание border-color, 1.1s step-end infinite
- `rshFloat`: стрелки «→» — translateY(0→-7px→0), 2.8–3s ease-in-out infinite
